title: Item transaction history and request emails
category: feature
released_at: 2026-08-05
deep_link: /transactions/index.php
---

Item pages now show transaction date, quantity, site, activity, and who performed it; older imported items show a clearly labelled opening snapshot instead of an empty panel.

Asset Management requesters also receive itemized emails when a request is submitted, approved, fulfilled, rejected, or cancelled. Stock creation, edits, checkout/check-in, production, allocation, and dispatch now add linked transaction entries automatically.
