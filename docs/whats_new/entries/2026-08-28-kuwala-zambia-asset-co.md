title: Kuwala added as the Zambia asset-co organization
category: feature
released_at: 2026-08-28
deep_link: /requests/workflow-view.php
---

The Zambia organization was split into an asset company and an operating company. The asset co is now represented as **Kuwala** (org id `kuwala`); the name **1PWR Zambia** (org id `1pwr_zambia`) belongs to the operating company.

The AM org→country map now recognizes `kuwala` as a Zambia (ZMB) organization, so Kuwala-tagged assets and sites are scoped to Zambia correctly.
